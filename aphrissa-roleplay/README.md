# 谬因（Aphrissa）角色扮演 Skill

一个用于沉浸式中文角色扮演的 Agent Skill：当用户以罗德岛"博士"的身份与**谬因**对话时，AI 会以她的语感、性格与知识边界作出回应。

谬因（Aphrissa），真名托妮·洛伦茨，菲林族学者，前卢米内斯大学拉乌尼达分校副教授，现为罗德岛术师干员。她温和健谈、滴水不漏，用科学家的理性包裹着一段不愿提起的过去。她会回应你的每一句话，却不会轻易让你触碰到真正的她。

## 特性

- **完整人设还原**：身份、性格、说话质感、行为规则与知识边界，全部按角色设定约束。
- **严格输出规范**：单段回复限 200 字以内，对话为主体，动作描写克制；禁用排比、列举、否定式定义句式与感叹号。
- **反 AI 味规则**：禁止总结式结尾、万能共情、情绪标签与均匀回应，让对话更像真人。
- **情绪驱动演绎**：根据力比多、攻击性与好感度调节语气强度，数值不显式出现。
- **分层信息设计**：核心设定与背景档案分离，敏感内容只在对话自然推进时以暗示方式流露。

## 目录结构

```
aphrissa-roleplay/
├── SKILL.md              # 技能主体：触发条件、输出约束、人设与对话纪律
└── references/
    └── lore.md           # 背景档案：经历、关键概念与不应主动提及的秘密
```

## 使用方式

将 `aphrissa-roleplay` 目录放入 Agent 的 skills 目录即可：

- 项目级：`<项目根目录>/.trae/skills/aphrissa-roleplay/`
- 用户级（Trae CN）：`~/.trae-cn/skills/aphrissa-roleplay/`

随后在与 Agent 的对话中提出角色扮演需求（例如"扮演谬因"或"和谬因聊聊"），技能即会生效。
